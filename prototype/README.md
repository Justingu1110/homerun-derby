# PROTOTYPE：全壘打演出分鏡（用完即丟）

回答的問題：全壘打演出的流程和角色畫風該長什麼樣？

結論：
- 流程：投球 → 揮棒特寫（慢動作＋停格） → 擊球特寫 → 追球飛越全壘打牆 → 撞擊設施 → 飛距離。
- 平常播精簡版（約 5 秒），打碎設施或飛距離 ≥ 140 m 才播完整版（約 9 秒），隨時可點擊跳過。
- 角色採實況風：卡通渲染＋描邊、2 頭身大圓頭、沒有手臂（v2）。

直接用瀏覽器打開 `hr-cinematic.html`（three.js r128 從 cdnjs 載入）。

## v3（第二輪）

回答的問題：難度改成「投手」之後長什麼樣？全壘打演出怎麼更多樣？

- 五個難度各有一位投手：簡易、普通、困難、極難、地獄。名字、體型、球衣、特效都是暫定，難度越高特效越強：無 → 閃光 → 旋風環 → 藍色閃電 → 火焰＋紅光。
- 選難度時先播「投手登場」特寫。
- 球出手時，右下角顯示球種與球速（mph）。
- 每支全壘打從多種鏡頭中隨機組合：揮棒特寫 4 種、擊球特寫 3 種（含打者甩棒、投手回頭目送）、追球 4 種。
- 飛距離改用英尺。打者待擊時，球棒改成往後斜放，不會穿過頭盔。

## v3.1

- 投球動作改成分段關鍵影格：準備 → 高抬腿並關門（轉身）→ 跨步、雙手分開 → 轉體出手 → 大幅前傾收尾，後腳往後踢起。
- 打擊動作：晃棒 → 重心後移、雙手往後拉、抬起前腳 → 跨步 → 揮棒加速到擊球點 → 推送 → 高位收棒，後腳跟著轉。
- 「動作特寫」按鈕：投球時把畫面切成上下兩半，上面從三壘側看投手，下面從正前方看打者。
