# 角色改成柔和光影、沒有描邊，比例照實況野球

取代 ADR 0001 中「卡通渲染加黑色描邊」的部分；用 three.js 做 3D、模型用程式從基本形狀組出來、外觀由參數產生，這幾點不變。

試玩後，玩家用實況野球的遊戲截圖當作目標：要柔和寫實的光影和地面陰影，不要描邊；蛋形身體直接接大頭、沒有脖子，手套和鞋子都很大，帽子底下露出頭髮。原型 v4–v6 照這個方向做，在手機上確認過，所以角色材質改成會受光的標準材質，並開啟陰影，拿掉描邊用的外殼網格。

## Consequences

- 陰影和標準材質比卡通材質吃效能，陰影只涵蓋本壘到投手丘的範圍。
- 觀眾也改成一個個 Q 版小人，人數多，遠處要用比較簡化的畫法，歡呼動畫交給 GPU 計算。
- 原型 v6 保存在 `prototype/hr-cinematic` 分支。
