# 用 three.js 做 3D，角色走實況野球風的卡通渲染

畫面是這個遊戲的重點：全壘打演出需要在揮棒特寫、追球、撞擊設施之間切換鏡頭，還要讓設施碎裂飛散，這在 2D Canvas 上很難自然做到，所以我們用 three.js 做 3D，而不是 2D 插畫或像素風。角色參考實況野球：2 頭身大圓頭、沒有手臂（手腳浮在身體旁）、卡通渲染加黑色描邊；球場維持簡單的色塊風。所有模型都用程式從基本幾何形狀組出來，不依賴外部美術素材，之後要支援自創角色時，只要改變外觀參數即可。

## Considered Options

- **2D Canvas**：最輕量，但鏡頭切換和碎裂效果要靠大量手繪素材。
- **2D 插畫風**：最好看，但每個畫面都需要準備圖。
- **像素風**：素材容易準備，但做不出誇張的特寫衝擊感。

## Consequences

- 只能參考實況野球與 Homerun Battle 的風格，不能使用它們的角色或素材。
- 全壘打演出的分鏡原型保存在 `prototype/hr-cinematic` 分支。
